# KillToGrow (KTG)

A Roblox game where players kill enemies to grow and level up.

## Project Structure

This project uses [Rojo](https://rojo.space/) for development and [Selene](https://kampfkarren.github.io/selene/) for linting.

### Key Systems

- **Blaster System**: Weapon infrastructure with aim assist, recoil, and visual effects
- **Game Loop**: Core game systems including progression, scaling, killstreaks, and bot management
- **Progression**: Level-based scaling system with meta-progression
- **UI**: HUD, killfeed, damage numbers, and admin panel

## Setup

1. Install [Rojo](https://rojo.space/docs/installation)
2. Install [Selene](https://kampfkarren.github.io/selene/installation.html) (optional, for linting)
3. Open the project in Roblox Studio using Rojo

## Development

- Source code is in the `src/` directory
- Project configuration is in `default.project.json`
- Linting configuration is in `selene.toml`
